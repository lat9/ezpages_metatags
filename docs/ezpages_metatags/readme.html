What it does

This now-encapsulated plugin adds three (3) additional fields in your admin's Tools :: EZ-Pages where you can enter the meta title, keywords and description for each page. Values you enter here override the built-in Zen Cart meta-tag processing for that page. The admin-level tool is updated to show the meta-tags' on/off icons depending on whether or not meta-tags have been defined for a given EZ-Page.

Three additional fields are added to your Zen Cart's ezpages_content table when the plugin is installed via the admin's Modules :: Plugin Manager:

  1. pages_meta_title
  2. pages_meta_keywords
  3. pages_meta_description

Notes:

  1. Before you install EZ-Pages Meta-Tags v5.0.0 (or later), you'll need a working copy of Zen Cart 2.1.0 or later.
  2. If an EZ-Page has been configured to use an External Link URL, then the page's metatags are not used, since the link is going to an external page!
  3. If a store has installed a version of EZ-Pages Meta-Tags prior to v4.0.0, the admin-installation copies any recording of the meta-tags' information from the site's ezpages table to the ezpages_content table … and then removes that content from the ezpages table. Be sure to make a backup copy of your database prior to installation, if this applies to your store!
  4. If you're installing on a site that has a version of this plugin prior to 5.0.0 installed, the encapsulated-plugin's installation will permanently delete the files from the non-encapsulated version.

Installing, Upgrading or Uninstalling

These sections identify the processes you'll use to initially install EZ-Pages Meta-Tags, upgrade or uninstall the plugin entirely.

Initial Installation or Upgrade

Start by copying the EZ-Pages Meta-Tags distribution's zc_plugins directory (and all its files) to the root of your site's file-system. You should see a zc_plugins/EzpagesMetatags sub-directory when completed and …

  1. Login to your Zen Cart's admin
  2. Navigate to Modules :: Plugin Manager.
  3. Click on the row that displays a Plugin Key of EzpagesMetatags and click the associated Install button.
  4. All finished! You'll now see metatag-related fields when you add or edit an EZ-Page.

Uninstalling

To uninstall EZ-Pages Meta-Tags …

  1. Navigate to your Zen Cart admin's Modules :: Plugin Manager.
  2. Click on the row that displays a Plugin Key of EzpagesMetatags and click the associated Un-Install button.
  3. From the confirmation form, click that Un-Install button. That button-click will "inactivate" the plugin.
  4. If you also want to remove the files associated with the plugin, click the Clean Up button.
